# 遺伝子発現データのデータ管理・クラウド移行プロジェクト

## 1. 全体概略（設計目的と思想）

### 1.1 プロジェクト概要

本プロジェクトでは、変形性関節症（Osteoarthritis: OA）に関する遺伝子発現データ分析プロジェクトで得られた解析結果を対象に、データベース設計、データ管理、およびクラウド環境への移行を実践しました。

ローカル環境に構築したPostgreSQLデータベースに分析結果を格納し、SQLによるデータ検索・検証を行った後、Amazon RDS for PostgreSQLへデータを移行しました。

本プロジェクトの目的は、分析結果を再利用可能な形で管理するとともに、データベース構築からクラウド移行、移行後のデータ整合性確認までの一連の工程を実践することです。

### 1.2 設計目的

本プロジェクトでは、以下の点を目的として設計・構築を行いました。

- 遺伝子発現解析で得られたデータを、構造化されたデータベースとして管理する
- 遺伝子、サンプル、解析結果を関連付け、SQLによる検索・集計を可能にする
- ローカル環境でデータベースを構築し、データ管理の基礎を確認する
- Amazon RDSを利用して、クラウド上のPostgreSQL環境を構築する
- ローカルデータベースからクラウドデータベースへの移行を実践する
- 移行後にレコード数や主要な解析結果を照合し、データの整合性を確認する

### 1.3 設計思想

本プロジェクトでは、分析結果を単にCSVファイルとして保存するだけでなく、データベースに格納することで、検索性・再利用性・管理性を高めることを重視しました。

また、クラウド移行においては、データを移行すること自体を目的とせず、移行前後のデータが一致していることを確認する工程を設けました。

ローカル環境での検証を経てクラウド環境へ移行することで、構築時の問題を切り分けやすくし、データ管理の各工程を段階的に確認できる構成としました。

### 1.4 関連プロジェクト

本プロジェクトは、別途実施した遺伝子発現データ分析プロジェクトの成果を活用しています。

- **分析プロジェクト：** PythonおよびRを用いた遺伝子発現データの前処理・統計解析
- **本プロジェクト：** 分析結果のデータベース化、SQLによるデータ管理、AWS RDSへの移行

分析プロジェクトで得られたデータを本プロジェクトで管理することで、データ分析からデータ管理・クラウド構築までの一連の流れを実践しました。
